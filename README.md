# Basketball Scoreboard

A simple basketball scoreboard application that allows users to manually track and update the scores of two teams. It provides an easy way to tally points during a basketball game.

## Features
- Manually add points to each team
- Track Team A and Team B scores
- Simple and user-friendly interface
- Real-time score updates
- Easy score monitoring

## Purpose
Developed as a programming project to practice application development and basic scoring functionality.
